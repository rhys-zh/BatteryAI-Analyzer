# Real screenshots only / 仅存放真实截图

This directory is reserved for screenshots captured from a real, running
BatteryAI-Analyzer instance. No mockup or generated result should be presented
as an application screenshot.

本目录仅用于保存从真实运行的 BatteryAI-Analyzer 中截取的软件截图。请勿将设计稿、
生成式图片或虚构分析结果作为软件实拍图使用。

Recommended files / 建议文件：

1. `01-overview.png` — cycle-performance dashboard / 循环性能总览；
2. `02-charge-discharge-curves.png` — voltage-capacity curves / 充放电曲线；
3. `03-anomaly-exploration.png` — Isolation Forest results / 异常探索；
4. `04-data-quality.png` — validation report / 数据质量报告。

Before capture, use the bundled synthetic demo or data that is explicitly safe
to publish. Review the image for filenames, local paths, account information,
and experimental identifiers before committing it.

截图前请使用仓库内置合成数据或已确认可公开的数据，并检查图片中是否出现文件名、
本地路径、账户信息或实验编号等隐私内容。
